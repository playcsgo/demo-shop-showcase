## 商品介紹
合作寵物醫院的年度健康檢查：理學檢查、血液檢查、糞便檢查。下單時選擇時段，醫院確認後才付款成立。

## 適用情境
- 一年一次的例行檢查
- 老年貓狗，建議檢查得更頻繁

## 注意事項
- 檢查前請先禁食，時間依醫院通知
- 預約成立後可以改期，請提前聯絡客服
