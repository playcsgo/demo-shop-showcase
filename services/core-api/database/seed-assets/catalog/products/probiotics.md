## 商品介紹
多種菌株的粉狀益生菌，幫助維持腸道菌相平衡。粉末可以直接拌進食物。

## 適用情境
- 換食、緊張或環境改變時容易軟便的貓狗
- 想日常保養腸胃的家庭

## 成分
多種乳酸菌、益生質（膳食纖維）。

## 注意事項
- 拌在常溫或微溫的食物裡，不要加在熱食上
- 開封後放在陰涼乾燥處
