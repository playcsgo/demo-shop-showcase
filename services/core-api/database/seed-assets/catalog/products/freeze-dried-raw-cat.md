## 商品介紹
新鮮帶骨肉塊經過冷凍乾燥，把水分抽掉、保留肉的香氣和營養。可以直接吃、撒在飯上提味，或加溫水泡開當正餐。

## 適用情境
- 挑嘴、需要提高食慾的貓
- 想用常溫保存的方式餵生食的家庭
- 當作訓練或互動時的零食

## 成分
肉、內臟、碎骨，以及貓需要的牛磺酸、維生素和礦物質。不同口味的主要肉類不同。

## 注意事項
- 偶爾會看到很細的碎骨，這是保留天然礦物質的做法，已處理成貓可以安全吃的大小
- 開封後放在陰涼乾燥處，盡快吃完；沒有添加防腐劑
- 建議加水泡開再餵，可以順便補充水分
