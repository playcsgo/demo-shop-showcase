## 商品介紹
狗狗可以直接嚼的鈣質錠，加入維生素幫助吸收，適合成長期或獸醫建議補鈣的狗。

## 適用情境
- 獸醫建議補充鈣質的幼犬或成犬

## 成分
碳酸鈣、維生素、雞肉風味粉。

## 注意事項
- 請依餵食量表給予，不要因為狗狗愛吃就多給
