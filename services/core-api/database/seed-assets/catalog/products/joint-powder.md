## 商品介紹
以軟骨萃取的膠原蛋白為主，幫助維持關節的靈活度，粉末拌在食物裡就能吃。

## 適用情境
- 熟齡、體重較重的貓狗
- 活動量大、想預先保養關節的毛孩

## 成分
雞軟骨萃取物、葡萄糖胺、維生素。

## 注意事項
- 保養品需要持續吃一段時間才看得到效果
- 開封後放在陰涼乾燥處
